Coffee Chats MCP lets a program such as Claude act on your Coffee Chats account for you. That program is called an agent. This page defines the words the rest of the documentation uses, gives the addresses you need, and points you at the page that answers your question. After reading it you will know what a connection is, what it can reach, and where to start.

MCP is the Model Context Protocol. It is an open standard that lets an agent ask another service to run one named action, such as reading your contacts. Each named action is called a tool. A connection carries only the permissions you granted, and you can end it whenever you want.

<Info>
Across the whole tool catalogue, no tool sends an email and no tool spends credits. An agent cannot email anybody for you, and it cannot spend your credits.
</Info>

An agent host is the application your agent runs inside, such as the Claude Code command-line tool or Claude on the web. Coffee Chats has not yet run a connection with any agent host from end to end, so these pages do not promise that your host will work. The connector itself is live, and the [quickstart](/mcp/quickstart) is the procedure to follow. The [compatibility page](/mcp/compatibility) says which hosts are registered today.

## The words this documentation uses

The same word means the same thing on every page.

| Word | What it means |
| --- | --- |
| Connector | The Coffee Chats side of a connection. It is the program that answers an agent's tool calls at the connector address below. |
| Agent | A program that does work for you by calling tools instead of using the Coffee Chats screens. |
| Agent host | The application the agent runs inside. |
| Permission | One named thing you allow a connection to do, such as reading your contacts. |
| Connection | One agent host's authorized access to your account, holding the permissions you granted it. |
| Request | One change an agent has proposed and cannot make by itself. |
| Approval | Your decision in a browser about one request. |

## Service endpoints

You use the first two addresses yourself. Your agent host reads the last two on its own when it signs you in, and you never have to open them.

| Purpose | URL |
| --- | --- |
| MCP connector | `https://mcp.coffeechats.me/mcp` |
| Your connections page | `https://mcp.coffeechats.me/connections` |
| Protected resource metadata | `https://mcp.coffeechats.me/.well-known/oauth-protected-resource/mcp` |
| Authorization server metadata | `https://mcp.coffeechats.me/oauth/mcp/.well-known/openid-configuration` |

Give the connector address to your agent host. Open the connections page yourself to see what is connected and to end a connection.

## What reading this documentation does

Reading these pages installs nothing. It does not start sign-in, and it does not grant an agent anything on your behalf. Only the consent screen does that, and only after you sign in to Coffee Chats yourself.

Mintlify is the service that publishes this documentation site. Its documentation search connector is a separate thing from the Coffee Chats action connector. Documentation search is not enabled for this site. If it is ever enabled, it will search these published pages only, and connecting to it will not authorize an agent to reach your account. No page here carries any account data. See [compatibility](/mcp/compatibility) for the difference.
