---
title: Withdraw a request
description: Take back a proposal the student has not decided yet, read the two answers the withdrawal can give, and know what the student sees afterwards.
---

An agent can take back a request it made, while the student has still not decided and no work has started. This guide shows you how, what the two possible answers mean, and what the student sees once a request is withdrawn.

## Send the withdrawal

The tool is `actions.cancel`. It takes the request identifier and nothing else, and it is the one write tool that needs no idempotency key, because the identifier already names one request:

```json actions.cancel input
{ "operationId": "0123456789abcdef01234567" }
```

It needs the permissions the proposing tool needed, so a connection that has lost a permission cannot withdraw work it could no longer propose.

## Read the answer

There are two outcomes and no third.

A withdrawal that succeeds, and a repeat of one that already succeeded, both answer with a cancelled result. `OPERATION_CANCELLED` is the success here:

```json actions.cancel result
{
  "status": "cancelled",
  "scenario": "cancelled",
  "operationId": "0123456789abcdef01234567",
  "error": {
    "code": "OPERATION_CANCELLED",
    "retryable": false,
    "correlationId": "0123456789abcdef01234567"
  }
}
```

<Info>
Withdrawing twice is the same success. A repeat is safe.
</Info>

Anything else answers with a conflict. The student had already decided the request, or it had expired, or Coffee Chats had already started applying it:

```json actions.cancel result
{
  "status": "failed",
  "scenario": "conflict",
  "operationId": "0123456789abcdef01234567",
  "error": {
    "code": "VERSION_CONFLICT",
    "retryable": false,
    "correlationId": "0123456789abcdef01234567"
  }
}
```

Poll the request with its own tool to find out which of those happened. Do not retry the withdrawal: the request has moved on, and calling again returns the same conflict.

## Only your own requests

A withdrawal reaches only a request the calling connection itself created. An identifier that names anything else is refused with the fixed error text every read failure uses, and that answer says nothing about whether such a request exists.

## What the student sees

A withdrawn request leaves the student's waiting list with no notification. It appears under the section headed "Recent decisions" on the same page, with one sentence saying how it ended, so the student can still see what happened to it.
