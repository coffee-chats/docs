## Staying connected

`offline_access` is not a permission to read anything. It lets the agent host keep the connection alive with rotating refresh credentials instead of sending you back through sign-in. No tool requires it, which is why its last column reads "no tool uses it".

## Reading the table

The last column is the honest answer about what a permission buys. It lists the tools that use the permission today, generated from the same catalogue the connector registers. If a consent sentence ever sounds wider than that list, believe the list.

The [tool reference](/mcp/tools/overview) describes what each of those tools returns.
