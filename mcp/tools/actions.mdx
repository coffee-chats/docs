## `actions.cancel`

What this changes: Withdraw an action this client proposed for the authenticated student, while it is still waiting for the student's decision and no execution has started.

Permissions: This tool needs `profile:write`, which the consent screen describes as "Update your profile preferences, and propose booking page changes you approve".

Risk: `safe_write`. This tool withdraws a request the agent proposed and changes no setting of yours. It does not ask you to approve first, because a withdrawal writes nothing to your account and can only happen while you have not decided.

Shape 2, where `status` is `cancelled`, carries these top-level fields:

```json
[

```

### Outcomes

A call carries one of these two codes, and `OPERATION_CANCELLED` is the success.

| Code | What it means |
| --- | --- |
| `OPERATION_CANCELLED` | The request is withdrawn and nothing was written. A request this tool finds already withdrawn returns the same code, so withdrawing twice is the same success. |
| `VERSION_CONFLICT` | The request could no longer be withdrawn, so nothing was withdrawn and nothing was written. You had already decided it, or it had expired, or Coffee Chats had already started applying it. |
